# Portfolio writing preferences

Use natural, clear language throughout the portfolio. Explain specific design choices without inflated claims or invented results.
Do not use en dashes or em dashes in portfolio copy or new writing for this project. Use normal punctuation and words instead.

# Local project

The application is a published React bundle in dist/assets/app.js. Shared graphic artwork rendering is handled by we; collection pages are handled by Ge. Graphic design cards open a native dialog viewer rather than linking to Dribbble. Collection cover images use the first artwork and fade into the page background.
AfriScale content is editable in content/afriscale.json; apply with python3 scripts/update-content.py.
Run locally with python3 scripts/serve.py.
